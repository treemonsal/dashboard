# Zuverlässigkeit, PDF Import und Portfolio

Basis: GitLab main 1b993729. Umsetzung vom 14.11.2026.

* Wiederholungen: eindeutiger Herkunftslink, atomare Speicherung, Schutz bearbeiteter Folgeaufgaben und ihrer Unteraufgaben. Historische Aufgaben ohne Link werden nicht geraten oder automatisch entfernt.
* Rückzahlungen: manuelle Ja/Nein Vorgaben bleiben bei späteren Abgleichen erhalten.
* Gesundheit: fehlende Tage werden in begrenzten Bereichen nachgeholt. Teilfehler verschieben den Fortschritt nicht. Schritte zeigen nur heute, ältere Messwerte ihr Datum.
* Formulare: Entwürfe bleiben bei Fehlern erhalten. Laden, Fehler und tatsächlich leere Daten sind unterscheidbar, auch bei abgelaufener Anmeldung.
* PDF: korrekter JavaScript MIME Typ für .mjs hinter KV, neue Worker URL gegen alte Cacheantworten, verständliche Fehlermeldungen. Keine stille Kürzung nach 80 Seiten.
* Export Version 2 enthält zusätzlich Trainings, Kalenderdaten und Abgleichhistorie, ohne Kalenderzugangsschlüssel oder OAuth Tokens.
* Tagesablauf und Jahreskarte sind vertauscht. Navigation unverändert.
* Portfolio: VUAA 12.2, XNAS 23 und NVIDIA 3. Bewertung anhand gleicher Anteilsklassen bei Tradegate in EUR und Umrechnung nach CHF. Bestehende Einzelkonfigurationen bleiben erhalten und können explizit übernommen werden. Kein unvollständiger Gesamtwert bei fehlenden Kursen, keine erfundene Historie. Details in depot.md.

## Prüfung und Veröffentlichung

`npm test`: 486 Server Tests und 11 Client Tests erfolgreich. Testworker auf zwei begrenzt, damit der bestehende Kalender Geschwindigkeitstest nicht mit 26 Isolaten um CPU konkurriert. Die Zeitgrenze wurde nicht verändert.

Browserprüfung mit synthetischen Revolut/Yuh PDFs auf mobiler Bildschirmgrösse: alter MIME Typ reproduziert den Fehler, korrigierter Typ erreicht die Vorschau. Kein echter iPhone Gerätetest und keine Originalkontoauszüge verwendet.

Vor Live Veröffentlichung Datenbank sichern, Migration 0009_integrity.sql anwenden und danach den Worker samt statischen Dateien gemeinsam veröffentlichen. Die Migration ergänzt Spalten und einen Index; vorhandene Arbeitsdaten werden erhalten. Ein reines Deployment ohne Migration ist unvollständig. Cloudflare Anmeldung ist in dieser lokalen Umgebung nicht vorhanden.
